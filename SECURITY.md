# Security policy — proposed

**Do not file public exploit details** for a running deployment. Use GitHub's private vulnerability reporting after the official repository is established and that feature is enabled, or a maintainer-approved security contact (not yet designated).

Report: affected version/commit, severity, safe reproduction, affected tenant/object, impact, and mitigations. Do not test against other people's deployments without authorization.

Threat model: `docs/05-security/threat-model.md`; detailed controls: `docs/05-security/security-requirements.md`. This document is a draft, not evidence of security certification.
